ElectroGrid – Electricity Service Management Web Application

ElectroGrid is a Java-based web application developed as part of a Programming Applications and Frameworks (PAF) project. The project focuses on building backend services for an electricity utility management system, using REST-based web services and relational database integration to support structured service operations.

Key Technical Highlights

Backend Development: Implemented a Java-based web application using Jersey (JAX-RS) for RESTful web services.

Database Integration: Used MySQL to support relational data storage and database connectivity.

API Development: Worked with REST-based service architecture for application-to-database communication.

Build & Dependency Management: Used Maven to manage project dependencies and package the application as a deployable WAR file.

Supporting Libraries: Included Gson and Jsoup in the project dependency configuration.

Technology Stack: Java, Jersey (JAX-RS), MySQL, Maven, Gson, Jsoup.

This project provided practical experience in Java backend development, RESTful web services, database integration, and web application architecture while exploring software solutions for electricity utility service management.
